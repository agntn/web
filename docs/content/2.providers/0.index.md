Every search provider answers the same `search()` with the same `SearchResult`. Six of them also `read()`, one also `searchByImage()`. What changes is the API behind it, the filters it can honour, which optional fields it fills, and what ends up in `metadata`. The pages are short on purpose. The part worth reading on each one is the gotcha list.
